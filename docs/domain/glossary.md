# Glosario (lenguaje ubicuo)

Términos del dominio de Edooca. Si una palabra no está aquí, todavía no forma parte del modelo.

| Término | Significado | No confundir con |
|---|---|---|
| **Familia** | Grupo que reúne a los tutores y estudiantes que comparten el seguimiento educativo. No implica parentesco legal. | — |
| **Tutor** | Adulto de la familia que crea contenido, lo asigna y hace seguimiento de los estudiantes. | Profesor (Edooca no tiene profesores) |
| **Estudiante** | Miembro de la familia que realiza retos y pruebas con su propia cuenta. | — |
| **Relación** | Etiqueta descriptiva de cómo se relaciona un tutor con un estudiante (padre, madre, tío, hermano, tutor legal…). Informativa: no cambia lo que el tutor puede hacer. | Rol (el rol es Tutor o Estudiante) |
| **Reto** | Contenido para **practicar**. Sirve para que el estudiante aprenda y refuerce. | Prueba |
| **Prueba** | Contenido para **determinar el nivel** del estudiante en una asignatura. | Reto |
| **Pregunta** | Unidad dentro de un reto o una prueba. Su **tipo** define cómo se responde y cómo se corrige. | — |
| **Tipo de pregunta** | Formato de una pregunta: opción múltiple, numérica, abierta… | Asignatura |
| **Asignatura** | Clasificación del contenido por área (Matemáticas, Inglés…). No cambia la forma de las preguntas. | Tipo de pregunta |
| **Intento** | Un estudiante concreto realizando un reto o una prueba: sus respuestas, resultado y fecha. | Reto / Prueba (el contenido) |
| **Visibilidad** | Qué puede ver un tutor de lo que han definido otros tutores de la misma familia. | — |
| **Puntos** | Mide el **esfuerzo**: el estudiante los acumula con cada reto y prueba que hace (más actividad, más puntos). Se pueden canjear, p. ej. para repetir una prueba. | Nivel |
| **Nivel** | Mide la **competencia**: lo que el estudiante sabe en una asignatura. Lo determinan sobre todo las pruebas. No se gasta. | Puntos, Nota escolar |
| **Progreso** | Evolución del estudiante dentro de Edooca. | Nota escolar |
| **Nota escolar** | Calificación real del colegio, registrada por el tutor o importada. | Progreso, Nivel |
